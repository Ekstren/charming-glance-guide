# Mined SxS game-data snapshots

This directory contains normalized **game facts/data** extracted from public datamine-backed Sword x Staff tools. It is intentionally not a mirror of any third-party website. UI code, CSS, images/audio, editorial recommendations, and long prose/descriptions are excluded.

`manifest.json` records the exact upstream commit(s), source paths, hashes, outputs, and any data-bearing files the importer could not normalize automatically.

Use these snapshots as reference inputs for our own calculator/build logic. Future-season data should remain dormant until separately validated for the active Global season.
